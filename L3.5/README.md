# L3.5: EventBooker — сервис бронирования с дедлайнами

Сервис для бронирования мест на мероприятия  с автоматической отменой неоплаченных бронирований.

## Архитектура

* **HTTP API (chi)**: Принимает запросы на создание мероприятий, бронирование и оплату мест.
* **PostgreSQL**: Хранит мероприятия (`events`) и места (`seats`) с текущими статусами.
* **Cron-like Scheduler**: Фоновый процесс, который каждые 15 секунд проверяет просроченные бронирования и автоматически освобождает неоплаченные места (таймаут — 2 минуты).
* **Веб-интерфейс**: Две страницы — пользовательская (бронирование/оплата) и администраторская (создание мероприятий, мониторинг).

## API

### Создание мероприятия
**POST** `/events`
```json
{
  "name": "Концерт",
  "description": "Описание",
  "event_date": "2026-06-15T18:00:00Z",
  "capacity": 50
}
```

### Получение списка мероприятий
**GET** `/events`

### Получение мероприятия с местами
**GET** `/events/{id}`

### Бронирование места
**POST** `/events/{id}/book`
```json
{
  "seat_id": 1
}
```
> Бронь действует 2 минуты. Если не оплатить — место автоматически освободится.

### Оплата (подтверждение) брони
**POST** `/events/{id}/confirm`
```json
{
  "seat_id": 1
}
```

## Запуск

### Docker Compose 

```bash
cd L3.5
docker compose up --build
```

Это поднимет:
1. **PostgreSQL** (порт 5435)
2. **Миграции** (автоматически)
3. **Сервер** (порт 8080)

Открыть в браузере: [http://localhost:8080](http://localhost:8080)

---

### Локальный запуск (без Docker для сервера)

1. **PostgreSQL в Docker**
```bash
# Поднять только БД
docker compose up postgres -d
```

2. **Миграции**
```bash
cd L3.5
go run ./cmd/migrate/main.go -action up
```

3. **Запуск сервера**
```bash
cd L3.5
go run ./cmd/server/main.go
```
